# Google 网盘批量下载器

一个用 Python 编写的 Google 网盘（Google Drive）文件批量下载工具。**只使用 Python 标准库**，无需安装任何第三方依赖。粘贴链接，每行一个，即可多线程批量下载；还支持批量下载并重命名，可直接从谷歌表格粘贴链接和新文件名。

## 功能

- **批量下载**：每行粘贴一个链接，自动去重，多线程并发下载（线程数可调，1–32）
- **批量下载并重命名**：左边贴链接，右边写新文件名；一键从谷歌表格粘贴（A 列链接、B 列新文件名）
- **断点续传**：下载中的文件保存为 `.part`，中断后重新运行会接着下载
- **失败自动重试**：网络错误自动重试 3 次；已存在的文件自动跳过
- **大文件支持**：自动处理 Google 的“无法扫描病毒”确认页
- **Google 文档支持**：文档、表格、幻灯片分别导出为 docx、xlsx、pptx
- **界面**：Tkinter 图形界面，浅色 / 深色主题一键切换（自动记住选择），带总进度条和状态着色

## 运行环境

- 建议使用仍在安全维护期内的 Python：3.11 及以上（据 endoflife.date：3.9 已于 2025-10 停止安全维护，3.10 已于 2026-10 停止）；代码本身没有用到新语法，较旧版本通常也能运行，但不建议
- 图形界面需要 Tkinter：Windows 和 macOS 的官方 Python 安装包自带；Debian / Ubuntu 需要 `sudo apt install python3-tk`

## 使用方法

1. 在文本框里粘贴链接（每行一个），选择保存目录和线程数，点“开始下载”。
2. 需要重命名时，点“批量下载并重命名”，在弹出的窗口里：
   - 左边贴链接，右边写新文件名，同一行对应；
   - 或者在谷歌表格里选中 A、B 两列并复制，点“从谷歌表格粘贴链接和重命名”，会自动填入（第一行如果是表头会自动跳过）；
   - 点“开始下载并重命名”，进度显示在主窗口。

### 重命名规则

- 新文件名不带扩展名：自动沿用原文件的扩展名（`视频01` → `视频01.mp4`）
- 新文件名已带原文件的扩展名：原样使用
- 新文件名留空：保持原文件名
- 文件名中的 `\ / : * ? " < > |` 会被替换为下划线；Windows 保留名（如 `CON`）会自动加前缀

## 安全说明

- 只访问 Google 域名：重定向和确认页里的下载地址都会校验，非 https 或非 Google 域名一律拒绝。
- 文件名会被清理，防止路径穿越、不可见字符伪装扩展名和 Windows 保留名；临时文件拒绝写入符号链接。
- 程序不保存任何账号、密码或令牌。唯一的配置文件是用户目录下的 `.gdrive_downloader.json`，只记录主题、保存目录和线程数。
